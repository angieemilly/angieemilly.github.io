# Mi Control

App personal de Angie para organizar estudio, trabajo y finanzas.

- **Mi agenda** (`index.html`): tareas con fecha de entrega y cuenta regresiva, registro hora a hora y vista semanal.
- **Mis finanzas** (`finanzas.html`): cuentas (efectivo, Nequi, bancos), plata apartada, deudas, pagos fijos y capacidad de pago.

Se instala en el celular desde https://angieemilly.github.io y funciona sin internet. Los datos se guardan solo en el celular (no en este repositorio).
